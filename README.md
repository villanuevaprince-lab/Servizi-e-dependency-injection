# Servizi e dependency injection
Esercitazione Angular basata sulla dispensa: esempio Hamburgeria con servizio condiviso, dependency injection, signal/computed e routing. Sono svolti anche i tre esercizi PROVA TU: verifica singleton, metodo togliUno e computed piattoPiuOrdinato.

## Avvio
npm install
npm start

## Test
npm test -- --include src/app/services --watch=false
